Answers are instant now. That changes how you think.

Asking AI isn't the problem. What slips away is the habit of trying to answer first, and nobody notices it going.

  1. 01

    You don't have to wait for answers anymore

    Finding something out used to mean searching, reading, or asking someone. Now a complete answer shows up in seconds, for almost anything. When nothing makes you wait, you stop trying first.

  2. 02

    Your memory relaxes when something else holds the answer

    Psychologists call this cognitive offloading: when you know an answer is stored somewhere else, you put less effort into remembering it. That's fine for phone numbers. It costs more when it's how you debug, write, or reason through a problem.

  3. 03

    Trying first helps you remember, even when you're wrong

    Research on the generation effect and retrieval practice keeps finding that attempting an answer before seeing the right one helps you remember it better. A wrong guess still helps.

  4. 04

    Nothing tracks what you hand off

    Screen time apps count hours. None of them show which kinds of thinking you now leave to AI, or in which fields.

Every field. Every kind of request. One record.

Each prompt is filed twice: by field, from software to law to medicine to your own writing, and by request type: explain, write, fix, summarize, decide, translate. Over time you can see what you still work out yourself and what you now hand to AI.

Questions

Can I skip the guess?

Yes. Press Esc to skip any guess, set a minimum message length, or only be asked on the tasks you use AI for most. Skips are logged too, so you can see how often you use them.

Which AI tools does it work with?

The guess box works on Claude, ChatGPT, and Gemini in the browser. Prompt counting also covers Perplexity, Microsoft Copilot, DeepSeek, Grok, Mistral Le Chat, and Poe. The Mac app counts Claude Code, Codex CLI, and Gemini CLI, and time in desktop AI apps.

Can you read my prompts?

No. There is no Think First server and no account. Prompts, guesses, and stats are stored on your own device. Comparisons use the AI model built into Chrome, which runs locally. If you add your own API key instead, the question, guess, and answer go to that provider under your account.

Is it really free?

Yes. Think First is free and open source. The optional API key route costs a fraction of a cent per comparison, billed by the AI provider to your own account.

What can't it see?

Prompts typed inside desktop apps (only time is counted there), chat panels inside code editors, and browsers without the extension, such as Safari and Firefox.

Does it work on Windows?

The browser and VS Code extensions do. The whole-computer tracker runs on Windows and Linux with Python, but there is no one-click installer for them yet.

Install steps

  • Browser extension

    Chrome, Edge, Brave, Arc

    1. Download the zip and unzip it.
    2. Open chrome://extensions and turn on Developer mode.
    3. Click Load unpacked and choose the unzipped folder.
    1. Open the store page and choose Add to Chrome.
    2. Pin Think First from the puzzle-piece menu.
    3. Reload any open AI chat tabs.

  • Mac app

    macOS 11 or later

    1. Download and open the zip, then drag Think First into Applications.
    2. Open it. If macOS says it can't verify the app, open System Settings, go to Privacy & Security, and click Open Anyway.
    3. If asked to install Command Line Tools, accept, then open Think First again.
